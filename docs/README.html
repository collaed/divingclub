DivingClub-Manager Documentation

🤿 DivingClub-Manager

Open-source diving club management system. Built with Laravel 11, MySQL 8, Blade, and Bootstrap 5. Multi-language, multi-club, mobile-ready.

Originally developed for the Club Européen de Plongée (CEP) in Luxembourg, but designed to work for any diving club worldwide.

Quick Start

git clone https://github.com/collaed/divingclub.git
cd divingclub
composer install
npm ci && npm run build
cp .env.example .env
php artisan key:generate

# Database
php artisan migrate
php artisan db:seed
php artisan db:seed --class=CertificationLevelSeeder
php artisan db:seed --class=SampleDataSeeder

# Storage & serve
php artisan storage:link
php artisan serve --port=8080

Wasmer / Edge / Docker

The app is a standard Laravel 11 application. It should work on any PHP 8.3+ hosting that supports MySQL. For Wasmer Edge specifically:

  • ✅ PHP runtime supported via WCGI
  • ✅ Static assets served normally
  • ✅ MySQL — use an external managed database (PlanetScale, Railway, etc.)
  • ⚠️ Email — configure an external SMTP provider (Mailgun, Resend, etc.) or set MAIL_MAILER=log for testing
  • ⚠️ File uploads — use S3-compatible storage (FILESYSTEM_DISK=s3) since local storage may not persist
  • ⚠️ Queues — use QUEUE_CONNECTION=sync unless you have a worker process
# Build for Wasmer
wasmer deploy --app-name=divingclub

User Stories

Public Visitors

  1. As a visitor, I can browse the club’s public pages (schedule, values, history, contact) without logging in
  2. As a visitor, I can request a free trial dive session via the trial page
  3. As a visitor, I can calculate membership dues using the public calculator
  4. As a visitor, I can view the site in any of 11 languages with automatic browser detection

Members

  1. As a member, I can log in and manage my profile, emergency contacts, and certifications
  2. As a member, I can register for upcoming events and see my position on waiting lists
  3. As a member, I can view dive sites with maps, weather, and safety documents
  4. As a member, I can read articles in my preferred language via auto-translated tabs
  5. As a member, I can switch languages and have my preference saved for future visits
  6. As a member, I can post and manage classified ads (gear for sale, buddy requests) with 30-day auto-expiry
  7. As a member, I can comment on articles in threaded discussions
  8. As a member, I can participate in votes (simple or election) via secure tokens
  9. As a member, I can view the instructor availability calendar to see who’s teaching when
  10. As a member, I can export my personal data (GDPR) or request account erasure
  11. As a member, I can install the app as a PWA on my phone
  12. As a member, I can generate SEPA QR codes for quick payment
  13. As a member, I can browse the document library for club files and resources
  14. As a member, I can use the dive group planner to organize buddy pairs

Instructors

  1. As an instructor, I can mark my availability on the weekly calendar by activity type
  2. As an instructor, I can see other instructors’ availability at a glance (color-coded initials)
  3. As an instructor, I can manage event registrations and check medical compliance

Bureau (Admin)

  1. As an admin, I can manage all members, roles, statuses, and certifications
  2. As an admin, I can create and manage events with recurring patterns
  3. As an admin, I can send targeted emails to member groups using templates
  4. As an admin, I can reconcile bank statements against expected payments with fuzzy matching
  5. As an admin, I can manage equipment inventory, loans, and maintenance schedules
  6. As an admin, I can create and manage votes (simple polls or formal elections)
  7. As an admin, I can publish articles in 13 types and trigger auto-translation to all languages
  8. As an admin, I can manage the document library with folder organization
  9. As an admin, I can customize the club’s visual theme from 6 presets or custom colors
  10. As an admin, I can configure club identity (name, address, IBAN, warehouse) without touching code
  11. As an admin, I can manage trial dive requests from the public
  12. As an admin, I can impersonate any member to troubleshoot their experience
  13. As an admin, I can view dashboard statistics with charts and export data as CSV
  14. As an admin, I can manage the license key for clubs exceeding 100 members
  15. As an admin, I can follow the 21-page in-app admin guide for setup and operations
  16. As an admin, I can create, inspect, download, and delete backups (DB + files) from the admin UI
  17. As an admin, I can view the bureau worklist on the dashboard showing pending actions (unverified certs, expiring medical, missing IBAN, minors without guardian, upcoming birthdays)

System

  1. The system automatically sends medical certificate expiry reminders at 30/15/7/0 days
  2. The system blocks event registration for members with expired medical certificates
  3. The system auto-opens and auto-closes votes at scheduled times
  4. The system performs weekly full backups (DB + files) retaining the last 4
  5. The system verifies RSA-signed licenses and blocks registration when invalid (>100 members)
  6. The system stores article translations for instant display without re-translating
  7. The system supports both MySQL and SQLite databases with automatic detection

Certification Levels

105 levels across 11 federations: FFESSM, LIFRAS, FLASSA, NELOS, VDST, PADI, SSI, UCPA, BSAC, NASDS, CMAS.

Cross-federation equivalence groups enable comparison (e.g., FFESSM N1 ≈ PADI OWD ≈ CMAS 1★ ≈ LIFRAS P1).
